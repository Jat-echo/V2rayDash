# 2026-10-31 默认自动同步上线

已接管节点保存配置变更后默认自动同步。后台每秒读取数据库中的 pending 节点，变更稳定约 5 秒后执行；批量和连续操作合并为一个节点任务。先处理落地依赖，再处理中转，自动与手动共用现有校验、备份、连通性检查及失败回滚流程。

候选配置与已核对哈希的运行配置相同，则只更新生效记录，不替换文件或重启代理。新增链路用户复用已生效的上游连接，只将中转加入任务队列。失败任务停止并保存原因，新的配置修改可重新排队，也保留“立即同步 / 重试同步”图标。名称、国旗、备注等显示信息修改不触发代理重启。

任务状态持久化在原 managed_nodes 中，没有新增队列表或依赖。账号及订阅配置修改与发布认领锁定同一节点记录，发布期间相关写入明确失败并回滚。补齐订阅启停、额度、删除、解除关联及更换目标等入口的任务标记，保留原有账号删除 / 解除关联语义。读取配置保留原先已有的待同步状态。

操作日志修正 JSON 序列化、无目标 ID 的批量日志及 JSON 读取，自动任务结果可查询；失败原因也显示在状态图标提示中。节点列表和链路页对 pending / publishing 状态自动刷新。
